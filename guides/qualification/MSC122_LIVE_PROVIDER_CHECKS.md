# MSC-122 — Live provider checks

Run separately, after the implementation checklist, in the configured live environment.
These checks do not gate local implementation or the 31-point checklist.

| Check | Status |
| --- | --- |
| Firebase login with real member, administrator and operator identities; session return, roles and logout. | **NOT DONE** |
| Configured Firebase messaging activation and actual browser push delivery. | **NOT DONE** |
| External account-warning email delivery with the public HTTPS link and unsubscribe. | **NOT DONE** |
| External ChatGPT/provider connection, OAuth consent/return and authenticated MCP request. | **NOT DONE** |
| Callback delivery over the public HTTPS endpoint with the real external receiver. | **NOT DONE** |
